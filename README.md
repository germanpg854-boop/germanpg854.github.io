# AeroMed Germany

A responsive, static multi-page website for GitHub Pages. This project updates the supplied website source files with AeroMed Germany branding while retaining the site's existing page names, navigation, guide content, official resource links, mobile menu, sitemap, robots file, and existing site address: https://germanpg854.github.io/.

## Project files

- `index.html` — homepage and pathways
- `language.html` — German language guide
- `approbation.html` — Approbation and recognition guide
- `exams.html` — FSP and Kenntnisprüfung guide
- `residency.html` — specialty training and residency guide
- `404.html` — not-found page
- `styles.css` — responsive visual styling
- `script.js` — mobile navigation and current year
- `robots.txt` and `sitemap.xml` — search engine discovery, retaining the current site address
- `assets/aeromed-germany-logo.png` — supplied logo, used in the site header and as the favicon

## Preview and edit

Open `index.html` in a browser to preview the site. Edit text and links in the `.html` files, and appearance in `styles.css`. This site is static: it does not provide accounts, member registration, private resources, a database, or a contact form backend. Email links open an email app; Instagram links go to `@germanpg854`.

## Put these files into the existing GitHub repository

1. Make a backup or download the current repository first.
2. Keep all project files together at the repository root, including the existing HTML pages, `styles.css`, `script.js`, `robots.txt`, `sitemap.xml`, and `assets/` folder.
3. Replace the corresponding files in the repository with these rebranded versions. Do not rename the HTML pages or change the existing site address, sitemap URLs, or guide links.
4. Review the changes in GitHub and commit them to the existing `main` branch. GitHub Pages should publish them using the repository's current setup.
5. Open https://germanpg854.github.io/ and check the home page, all guide pages, mobile navigation, email, Instagram, and not-found page after deployment.
